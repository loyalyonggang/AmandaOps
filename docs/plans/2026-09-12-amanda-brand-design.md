# Amanda 跨境工作台品牌设计

## 目标

把 IvyeaOps 的用户可见品牌统一为「Amanda 跨境工作台」，同时保留内部包名、API 路径、数据目录和 IvyeaAgent 名称，避免品牌改造破坏上游兼容性。

## 视觉方向

Logo 采用「字母 A + 跨境轨道」：深色圆角方形提供稳定底座，白色几何 A 保证小尺寸识别，青蓝轨道表达跨市场连接，金色节点表示目的地与成交。图形使用原创 SVG，不依赖外部字体、图片或商标素材；在深色、浅色主题以及 22px 侧边栏尺寸下都应保持清晰。

## 品牌范围

- 浏览器标题、登录页、侧边栏、首次设置向导、任务台和引导文案使用「Amanda 跨境工作台」或短名「Amanda」。
- 侧边栏、登录页、任务台、账户区与 favicon 使用 Amanda Logo。
- README 首屏改成 Amanda 品牌，并保留原项目、许可证和上游仓库归属说明。
- FastAPI 文档标题和健康接口服务名改为用户可见品牌。
- `IvyeaOps` 的 Python/TypeScript 模块名、环境变量、数据库路径、API 路径、更新机制及 IvyeaAgent 产品名保持不变。

## 验收

前端类型检查和生产构建必须通过；后端健康接口返回 Amanda 品牌；登录页和登录后侧边栏需在浏览器中目视确认新名称与 Logo，无拉伸、裁切或旧品牌残留。
